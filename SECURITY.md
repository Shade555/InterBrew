# Security Policy

## Supported Versions

Security fixes are currently applied to the `main` branch and the latest published release, when one exists.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Please report it privately through [GitHub's private vulnerability reporting](https://github.com/Shade555/InterBrew/security/advisories/new), if enabled, or contact the maintainers through a private GitHub message.

Include:

- A clear description of the vulnerability and its impact
- Affected files, routes, versions, or configurations
- Reproduction steps or a minimal proof of concept
- Any suggested mitigation

Please allow maintainers reasonable time to investigate and release a fix before publicly disclosing the issue. Do not include real credentials, personal data, or production secrets in a report.
